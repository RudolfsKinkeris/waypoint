# Log In Screen — Missing Username Validation

## Steps to Reproduce
1. Navigate to the Log In screen.
2. Leave the Username field empty.
3. Attempt to log in.

## Expected
An error message should appear telling the user to fill in the Username field.

## Actual
The user is logged in and taken to the Main page without entering a username.

## Severity
Critical
